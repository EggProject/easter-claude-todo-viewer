Menubar · top nav menus

A real <Menubar> following the APG menubar pattern: one Tab stop, arrow-key roving, typeahead, and checkbox items driven by React state. The component owns all roving, ARIA and panel wiring.

Top level

  • Tab enters the menubar once (a single tab stop).
  • ← / → move between top-level menus; Home / End jump to the first / last.
  • Enter, Space or ↓ opens a panel; ↑ opens it at the last item.
  • Type characters to jump between top-level menus.

Inside a panel

  • ↓ / ↑, Home / End move between items.
  • ← / → switch to the previous / next top-level menu.
  • Type characters to search within the current panel only.
  • Enter / Space activates; Esc closes and returns to the top-level trigger.
  • Tab / Shift+Tab leaves the whole menubar.
