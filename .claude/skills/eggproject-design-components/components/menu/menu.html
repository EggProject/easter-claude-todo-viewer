Menu · actions & options

A real <Menu> dropdown: a native button trigger, grouped items, leading icons, shortcuts, interactive checkbox items, and a destructive variant. Roving focus, typeahead and focus-restore are handled by the component — this page only supplies the data.

Keyboard

  • Tab moves to the trigger (a normal tab stop).
  • Enter or Space opens the menu.
  • ↓ opens and focuses the first item; ↑ opens and focuses the last.
  • ↓ / ↑, Home / End move between items (wrapping).
  • Type characters to jump to a matching item (typeahead).
  • Enter / Space activates; selecting an item closes the menu, so reopen to see a toggled check.
  • Esc closes and returns focus to the trigger.
  • Tab / Shift+Tab leaves the open menu.
