# v3.1 Flow, language preference, and UI behavior

- Flow x-order uses observed lifecycle/session timestamps; explicit task dependencies are the only graph edges.
- Manual node positions and viewport are persisted per session in `flow-layout.json`.
- Execution navigation is removed; legacy `/execution*` URLs redirect to Flow.
- Global/task HU switches represent desired language and are committed immediately. Failed translations fall back to English without reverting the preference.
- New/changed source text appears immediately, then automatically translates when HU is desired.
- Translation detail expands inline below its table row.
- Settings are card-grouped, task status filtering is a checkbox multiselect, and connection status is a tooltip-enabled dot before the logo.
