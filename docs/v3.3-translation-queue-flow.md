# v3.3 Translation Queue and Flow Full-size

- One `(uid, textFingerprint)` translation lifecycle row; duplicate v3.2 rows migrate into Run history.
- Bulk translation endpoint: `POST /api/translations/bulk` with actions `stop`, `retry`, `delete`, `stop_all`, `retry_all_failed`.
- Provider-specific `maxConcurrency` settings (default 2, range 1–32) are enforced across complete task translation lifecycles.
- Translation table supports checkbox selection, visible-row select-all, bulk actions and summary modals.
- Flow adds a custom React Flow `ControlButton` for native fullscreen with a browser-viewport fallback.
