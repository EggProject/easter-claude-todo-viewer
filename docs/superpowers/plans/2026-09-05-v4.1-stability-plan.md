# Claude Todos v4.1 Stability Implementation Plan

**Goal:** Fix Flow render loop, slow/laggy Sessions, missing/awkward session switching, add startup splash, rework header, and move session language control into Sessions.

**Architecture:** Preserve v4 daemon/client split. Make registry discovery cache-first, make client bootstrap staged, and make React Flow state ownership one-directional.

### Task 1 — Reproduce and test Flow feedback loop
- Add tests/source-contract checks for stable semantic graph revision and guarded viewport restore.
- Refactor Flow node reconciliation to depend on semantic revision + selected sessions, not layout object identity.
- Persist drags directly without mutating the layout object used to drive node reconciliation.

### Task 2 — Cache session discovery and make API snapshot-only
- Add transcript stat-signature metadata cache in `SessionRegistry`.
- Add `snapshot()` and cached `discover(force=False)` behavior.
- Change GET `/api/sessions` to snapshot only.
- Add POST `/api/sessions/refresh` for explicit refresh.
- Ensure background discovery remains incremental.

### Task 3 — Remove inactive runtime fan-out
- Add cache-only session stats / translation rows for inactive sessions.
- Change translations/catalog/session list paths to avoid `get_runtime()` for every discovered session.
- Instantiate only watched/current sessions or explicit action targets.

### Task 4 — Staged bootstrap splash
- Add AppProvider bootstrap state and minimal critical bootstrap.
- Add full-screen splash component with branded spinner, progress copy, error and Retry.
- Load heavy history/translations after shell is ready.

### Task 5 — Sessions UX and language control
- Move Action column next to Current and make sticky.
- Implement optimistic Switch with rollback.
- Add per-session EN/HU switch and pending/stop states; auto-watch before HU.
- Remove global language control from header.

### Task 6 — Header layout and task language badges
- Right-align nav, widen responsive session button.
- Add shared language badge helper/component to task surfaces.

### Task 7 — Verification and packaging
- Run all Python tests, Bash syntax, Python compile, JS syntax.
- Run multi-session HTTP/client smoke with synthetic sessions.
- Package v4.1.0, unzip the exact ZIP, rerun verification, generate SHA-256.
