# v4.1 stability changes

- Flow semantic/task state and user layout persistence are reconciled one-way to prevent React maximum-update-depth loops.
- Session discovery caches unchanged JSONL metadata by `(mtime_ns, size)` and normal `/api/sessions` reads a snapshot only.
- Session counters use an explicit invalidation cache rather than repeated filesystem walks.
- Client bootstrap has a static + React branded splash and staged critical/heavy data loading.
- Sessions Action is sticky/optimistic; per-session language control auto-watches HU sessions.
- Header has a wide responsive session button, right-aligned navigation and no global language switch.
- Task language badges are shared across task/flow/drawer/dependency/notification/history/translation references.
