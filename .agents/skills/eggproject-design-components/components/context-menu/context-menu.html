Context Menu · right-click

A real <ContextMenu>: right-click (or keyboard-open) a target to get a menu that clamps inside the viewport. The component supplies the focusable target wrapper, its ARIA, roving focus, typeahead and focus-restore.

Open & navigate

  • Right-click the target to open at the pointer.
  • Tab / Shift+Tab focuses the target — watch its focus-visible ring.
  • Shift+F10 opens from the keyboard; the Context Menu / Apps key works where available.
  • ↓ / ↑, Home / End move between items; type to use typeahead.
  • Enter / Space activates an item.
  • Esc closes and returns focus to the target (its ring shows again).
  • Tab / Shift+Tab leaves the menu; clicking outside closes it. Any scroll closes it.
  • Near a screen edge the panel clamps inside the viewport — try the box pinned to the bottom-right corner.
