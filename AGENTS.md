# Repository Guidelines

## Browser Verification Requirement
- Kötelező mindig tesztelni úgy is, hogy elindítod a teljes alkalmazást (backend és frontend szerver), és böngészőben végignyomogatja egy agent a `chrome-devtools` MCP eszközökkel.
- Minden Node, pnpm, vitest és npm parancs futtatásakor kötelező a `mise exec --` használata.
